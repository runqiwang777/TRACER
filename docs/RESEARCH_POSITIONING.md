# TRACER R1：研究重点与执行边界

更新日期：2026-11-02。本文对齐已审阅的研究计划 R1。当前 v3、既有输出和预注册继续保留；E3／E4 是后续设计，不是已经完成的新实验。

## 科学问题与四个 RQ

语言模型在形式化证明修复中，是否利用了诊断语义？什么信息在何种错误上有效，又如何转化为修复行为？

| RQ | 问题 | 主要观察 |
| --- | --- | --- |
| RQ1 | 是否超出再生成机会的收益？ | 同失败种子内真实结构化反馈与无内容重试 |
| RQ2 | 反馈语义是否影响行为？ | 真实／无关／反事实信息、预定义编辑方向与 Lean 结果 |
| RQ3 | 哪种表示有用？ | raw／normalized／structured 的信息覆盖、成功与实际成本 |
| RQ4 | 何时、如何起作用？ | 重复错误、信号解决、新错误和反馈选择 |

[Li 与 Li（2026）](https://arxiv.org/abs/2610.22698) 是反馈对照的重要参考。固定候选、匹配错诊断或模型替换本身不单独作为主要原创性主张。三个供应商模型提供独立验证范围，增量还需要真实项目、诊断信息结构及行为证据支撑。

## 三个预期贡献

1. **TRACER-REAL：** 真实历史修复、固定声明与环境、项目划分、来源账本和参考解隔离。
2. **诊断信息结构与语义响应：** 核对表示的信息保留、定向误导与编辑行为，并分析成功—成本权衡。
3. **Error-State 分析与反馈选择：** 从可核验信号到独立评测的确定性策略。Router 为次要、条件性贡献，未胜出也保留结果。

LeanCapsule、SP 和发布审计提供可信执行与复现支撑，不扩展为大量并列主贡献。

## E1：完成当前冻结 v3

DeepSeek `deepseek-v4-pro` 与智谱 `glm-4.5` 八臂，MiniMax `MiniMax-M3` 三条确认臂，各三重复。

主对比保持 `true_structured - content_free_retry`；同模型、同题、同重复、同首轮失败候选配对，按项目等权。当前模型、干预、排除、预算与输出目录不改写。每模型最低合格失败门槛、基础设施错误与其他确认性报告门禁按原预注册执行。

先完整核对种子、分支、重试、不适用和未知结果，再复编译全部成功证明，提供 AI 辅助复核及脱敏工件。当前仓库尚无全量审计的 v3 provider 最终结果包，不据此判断本机实验进程状态。

## E2：优先分析已有证据

核对 raw 到 normalized／structured 的标识符、expected／actual type、目标、类别与原文片段。来源可追溯不等于信息完整。

在同覆盖下分析编辑、错误转移、成功、token、反馈长度、编译调用和延迟。三种表示同时改变组织、长度与信息量，现有比较首先估计表示方案的整体效果。关键词变化不直接证明理解。

当前一步分叉只支持首轮到分支的一步转移，不把不同臂串成多轮。费用未知不记为 0；同输出上限不等于实际 token 匹配；未检出差异不等于等效。

## E3：拟新增定向语义干预

先离线盘点材料、字段与干预有效性，再用独立开发材料做流程 pilot，随后独立预注册并使用新目录和同期对照。必要条件拟包括重试、真实诊断、保留语义的改写、单字段定向错误；删除目标信号为可选条件。

生成前固定原始证据、变更字段、预期修改方向和有效性判定。CFR 报告有效干预、可判定响应及缺失分母；不能把编译失败或字符串复制直接计为语义跟随。

当前 counterfactual 分支不因名称相同而自动成为上述实验。若复用已查看的 test，应披露为已知评测集的后续研究；新日期输出不与可能漂移的旧 API 输出伪装成同期配对。

## E4：条件性反馈选择研究

现有 adaptive 原型照常分析。新策略仅用部署时可见的错误、信号、历史和预算，在开发材料上固定规则与基线，再在独立材料上验证。

现有 development／validation 仅 11 题，先盘点状态覆盖；不足则新增独立开发材料或收窄规则。事后 oracle 只能作为不可部署上界。已看过的 test 不称为未触碰测试集。

## 分析与时间安排

- 主对比与门禁沿原冻结文件执行；统计步骤逐条核对原文及代码，新选的检验、区间和标注不回填为预注册。
- 各模型先分别报告资格率、项目分布和主效应。重复与实验臂不扩充独立题目数。
- 五项目若采用双侧精确符号翻转检验，最小 p 值为 0.0625；重点报告效应与不确定性。
- 先完成 E1，再分析 E2，随后有条件开展 E3／E4。新任务量和价格先盘点，不提前虚构总费用。
- 12/23 是内部文稿目标；未过证据门禁则顺延，不为日期放宽审计。该日期不是核实过的会议投稿截止。
