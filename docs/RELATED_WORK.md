## 当前可检验的增量

1. **模型与供应商覆盖：** v3 在 DeepSeek、GLM、MiniMax 上分别估计同一失败种子内的反馈效应，再按冻结规则比较方向一致性。DeepSeek-v4-Pro 与 DeepSeek-Prover-V2-7B 是不同配置，不能因共享家族名称而等同；三家 API 的服务方式和隐藏训练数据也限制解释范围。
2. **真实项目修复：** TRACER-REAL v2 的 test 划分有五个独立项目、254 道历史修复题。声明和环境固定、参考证明隔离，按项目等权报告，检验超出单一竞赛题基准的适用性。
3. **反馈表示与机制：** 在原始、规范化、结构化诊断之外保留来源片段，检查相关代码修改、错误转移和动态检索。词法相关修改是行为指标，不能直接证明模型理解。
4. **可复核结果：** 将合格失败、排除、基础设施错误、全部成功证明、AI 辅助复核与脱敏轨迹一起审计，避免把再次采样机会或缺失记录误写为反馈效果。

Li 与 Li 的结果表明，其已测试条件未确立优于仅指令重采样的优势，并不排除其他模型、任务或诊断表示中存在不同效应。TRACER 的研究目标是检验这些条件差异；不同模型这一点具有独立复现价值，但尚不能代替效应估计，也不能据此宣称优于该论文。

当前实验沿 [v3 冻结协议](V3_EXPERIMENT_PROTOCOL.md)继续；新增分析若不在预注册中，应标为探索性或另立后续协议。研究定位更新不修改现有模型、实验臂、主终点或输出目录。
