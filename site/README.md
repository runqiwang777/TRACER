# TRACER project website

Published from the `site/` directory of the `runqiwang777/TRACER` repository to `https://runqiwang777.github.io/TRACER/`.

The English landing page is `index.html`; the Chinese page is `zh.html`; the 24-case static explorer is under `demo/`. No model API or credential is used by the site.

Evidence snapshot: 1 November 2026. The displayed 864-task and 811-proof figures summarize a previously audited repair24 release; that complete release currently remains in the local archive and is not contained in this repository. The 24 case pairs used by the demo are embedded in `demo/demo-data.js`. The 254-task TRACER-REAL v2 test set is frozen, while its v3 provider study has no accepted public outcome here.

Update both landing pages, `results.svg`, and the demo data together when evidence changes.
